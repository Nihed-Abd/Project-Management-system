# Project Management System

This repository contains the source code for a Project Management System developed by Nihed BenAbdennour.

## Overview

This system is designed to help organize, track, and manage projects efficiently. Built primarily with JavaScript, it offers features to support project planning, task assignment, progress tracking, and more.

## Features

- Project creation and management  
- Task assignment and progress tracking  
- User roles and permissions  
- Dashboard for project overviews  
- Notification system for updates and deadlines  

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Nihed-Abd/Project-Management-system.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
4. Access the system in your web browser at `http://localhost:3000` (default).
